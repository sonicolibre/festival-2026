# Festival Sónico Libre

Sitio estático listo para GitHub Pages. La página principal es `index.html`; no necesita compilación.

## Subir a GitHub Pages

1. Descomprimí el ZIP.
2. En el repositorio `festival-2026`, reemplazá los archivos de la raíz por `index.html`, `styles.css`, `script.js` y `favicon.svg`.
3. Subí también la carpeta `assets` completa, conservando las rutas y los nombres de archivo. En particular, el afiche debe quedar en `assets/flyer-sonico-libre.jpg`.
4. Confirmá el commit y esperá a que GitHub Pages publique los cambios.

No subas la carpeta contenedora del ZIP ni cambies los archivos de lugar: `index.html` y `assets` deben quedar juntos en la raíz publicada. Esta entrega no usa la carpeta `dist`.

## Botón de descuento

El botón `¡Accedé al descuento!` abre un nuevo correo dirigido a `sonicolibre7@gmail.com`, con el asunto y el mensaje ya escritos. La persona termina de enviarlo desde su aplicación de correo.
